# 台灣股東會紀念品查詢網站

GitHub Pages 靜態網站，查詢全台 2611 家公司股東會紀念品資料。

## 功能
- 公司代號/名稱搜尋
- 紀念品內容 + 狀態分類（有發/未定/不發/未知）
- 最後買進日、開會日顯示
- 深色主題，手機/桌機皆可看

## 資料
- `souvenir_db.json` — 自動抓取公開資訊觀測站資料
- 更新：使用 [souvenir-db](https://github.com/kuanghua-careagent/souvenir-db) 的 `build_db.py`

## 來源
- 官方：公開資訊觀測站 https://mops.twse.com.tw/
- 整理觀點參考：https://twsouvenir.github.io/
